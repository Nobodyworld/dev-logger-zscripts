# Support

Zscripts is archived and no longer actively maintained.

There is no active feature-development, bug-fix, dependency-maintenance, compatibility, or
response-time commitment. Existing issues, pull requests, plans, audits, and release records
are preserved for historical reference.

For self-service context, start with:

- [Archive decision](../ARCHIVE.md)
- [README](../README.md)
- [Repository Review Guide](repository-review.md)
- [Architecture](architecture/ARCHITECTURE.md)
- [Security policy](../SECURITY.md)
- [Historical task ledger](TASKLIST.md)

If you fork or reuse the code, you own current dependency/security review and validation. Do not
post credentials, private source, personal information, proprietary paths, or vulnerability
details to public historical threads.
