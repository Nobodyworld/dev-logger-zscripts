# Support

Zscripts is a public-beta structured log toolkit and experimental local
repository-review workspace for developers and automation systems.

## Community Channels

- **Questions and setup help**: Use the Question or Support Request issue
  template for non-sensitive usage, installation, and workflow questions.
- **Bugs and feature proposals**: Use the repository's Bug Report or Feature
  Request issue template and include the relevant CLI command, configuration,
  environment, and sanitized logs.
- **Security**: Follow the [SECURITY policy](../SECURITY.md) and use GitHub
  private vulnerability reporting. Do not disclose vulnerability details in a
  public issue.

GitHub Discussions are not currently enabled for this repository. Public support
routing must not depend on a Discussions URL.

## Availability

This public-beta project is maintained on a best-effort basis. It does not
offer response-time guarantees or private support channels.

Documents under `docs/plans/` are historical planning records unless a file
explicitly identifies itself as current and authoritative.

## Escalation

For additional non-sensitive assistance, open a Question or Support Request
issue with:

1. The relevant CLI or workspace action.
2. Sanitized log or error excerpts, including `event=` and `error_id=` markers
   when available.
3. `zscripts` version or commit, Python version, and operating system.
4. The expected result and the observed result.

Do not post credentials, private source, personal information, proprietary
paths, or vulnerability details. Support is best-effort and does not include a
guaranteed response-time service level.
