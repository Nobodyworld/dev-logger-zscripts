# Examples and Fixtures

The `examples/` tree groups sample projects, language-specific snippets, and
pre-generated artifacts that appear throughout the documentation and tests.

* `sample_project/` mirrors a small polyglot application used in walkthroughs.
* Language folders such as `python/`, `go/`, or `javascript/` contain minimal log
  samples that exercise adapters.
* `raw_to_report/` contains a complete raw-log to normalized and redacted-report
  walkthrough fixture set.
* `artifacts/` stores captured outputs that the documentation references.

Refer to `docs/guides/` for tutorials that make use of these assets.
