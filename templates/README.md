# Templates

Reusable scaffolding for documentation, issues, and automation output lives in
this directory. Copy the relevant template when bootstrapping a new helper or
document so the project tone and structure stay consistent.

- `issue/` — ticket templates for bug reports and feature requests.
- `docs/` — starter outlines for reference guides.

Whenever a template changes, update `README.md` and `SPEC.md` to point to the new
workflow so contributors discover it early.
